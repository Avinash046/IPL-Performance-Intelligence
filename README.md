IPL Performance Intelligence

Project Overview
SQL-based sports analytics system analyzing 200,000+ IPL 
ball-by-ball delivery records across 16 seasons (2008–2024)
using SQL Server (SSMS).

Tools Used
- SQL Server (SSMS 20)
- T-SQL
- Microsoft Excel

Database Schema
- matches (17 columns, 1000+ rows)
- deliveries (17 columns, 200,000+ rows)

 Modules
- Module 1 — Team Performance Analysis
- Module 2 — Player Performance Analysis
- Module 3 — Season Trends (Window Functions)
- Module 4 — Venue Intelligence
- Module 5 — Advanced Business Insights (CTEs)

Key Findings
1. Mumbai Indians — most wins overall across 16 seasons
2. Gujarat Titans — ranked #1 in debut season (2022)
3. Teams choosing to field after toss win 57% of matches
4. 2022 saw biggest scoring jump due to league expansion to 10 teams
5. Wankhede and Chinnaswamy are highest scoring venues
